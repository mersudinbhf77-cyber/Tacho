# Changelog

All notable changes to **Tacho Studio** will be documented in this file.

## [4.0.0] - 2026-11-14
### Added
- Open-source release of the EU Regulation (EC) No 561/2006 & AETR compliance analyzer.
- Direct PC/SC smart card reading (`winscard`) for Generation 1 (G1) and Generation 2 (G2) driver and company cards.
- Binary `.DDD` and `.C1B` file parser and raw dump exporter.
- Automated detection of daily, weekly, bi-weekly, continuous driving, and split/reduced daily rest rules.
- Export engines for A4 HTML reports, headless Edge/Chrome PDF generation, and Excel-compatible CSV tables.
- Unit test suite (`test_compliance.py`) and regulatory documentation.
